## Stack

| Camada | Tecnologia |
|---|---|
| Linguagem | Python 3.12+ |
| Framework | Django 6.x |
| Frontend | Django Template Language + TailwindCSS (CDN) |
| Banco de dados | SQLite |
| Autenticação | Django Auth com `CustomUser` (login por e-mail) |
| Gerenciador de pacotes | `uv` |
